# FAQ — Sixth-Dimension Theory (EAV-SDT-001)

## 1. Is the Sixth-Dimension Theory proven?
No. It is a hypothesis + experimental protocol. No data have been collected. It remains unestablished until registered experiments are completed and independently replicated.

## 2. What does "sixth dimension" mean here?
A perceptual-representational coordinate: x6 = G, the internally generated share of a percept. It is a degree of freedom of the percept descriptor, not a physical axis, not a place, and not travel.

## 3. Is this about parallel Earths / parallel worlds?
No. No parallel Earth, parallel world, or alternate reality is claimed. The theory is about perceived space, not physical worlds.

## 4. Can I travel to the sixth dimension?
No travel is claimed or offered. The "state" is a measured perceptual state (G ≥ 0.70 + Q ≥ 0.80), not travel, not a power, not an out-of-body experience.

## 5. Can I buy access to the sixth dimension / an experience / a power?
No. Nothing is sold. Funding does not buy access, results, authorship, or endorsement. Anyone selling access in this name is misusing the work — report it (see CONTACT.md).

## 6. What is G?
G = internal-generation index: the share of a percept that is mind-created (0–1). `G = 0.40·R + 0.30·U + 0.30·B`. R = neural decoupling (6 Hz SSVEP), B = behavioural decoupling (d′), U = reported internal generation (PSQ-6).

## 7. What is Q?
Q = source-attribution accuracy: `Q = ncorrect / 16`. After a window, 16 events (8 displayed, 8 imagined) are presented in random order. Participant states "displayed" or "imagined." Q* = 0.80 (13/16, chance 0.0106).

## 8. What is D?
D = state indicator. D = 1 if G ≥ 0.70 AND Q ≥ 0.80; otherwise D = 0. Evaluated once per 90 s state window.

## 9. What is V? What is the Cloud-Visibility Rule?
V = cloud-visibility indicator. V = 1 if cloud fraction c ≥ 0.003 AND Weber contrast Cw ≥ 0.02. Rule: `V = 1 → D = 0`. Visible cloud excludes the state. Absence of cloud is necessary but never sufficient, and never evidence for the state.

## 10. Why clouds? Isn't that circular?
No. D is defined by R, U, B, Q only — no cloud measure. V is scored by camera, blind to D. The rule forbids exactly one combination (V = 1 + D = 1). One verified counterexample falsifies the strong form.

## 12. Why take this seriously if it is not proven?
Because it is falsifiable. It states in advance what would reject each part: seven hypotheses, numerical thresholds, and a verdict matrix. A theory that can fail clearly is worth testing, even if it fails.

## 13. What is the first experiment?
E1 — Construct Validity: N = 42, 1,008 trials. Tests H1 (separability) + H2 (state exists / inducible). It also calibrates G* before E2.

## 14. What would falsify the whole theory?
If H1 or H2 are rejected, Postulates 2 and 3 are withdrawn and remaining tests are moot. If H3 is rejected, the Cloud-Visibility Rule is rejected (construct retained). If H4–H6 fail, the anchoring mechanism is rejected. If H7 fails, the perceptual-only claim is withdrawn.
