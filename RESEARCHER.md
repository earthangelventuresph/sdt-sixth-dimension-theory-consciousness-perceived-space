## Research Position

### What Is Asserted
- Perceived space can be described by six coordinates, with x6 = G, the internally generated share of a percept.
- A sixth-dimension state can be defined as D = 1 when G ≥ 0.70 and Q ≥ 0.80.
- Visible cloud is hypothesised to exclude that state (V = 1 → D = 0).
- Anchoring is hypothesised to explain the rule, with explicit parameters.
- Seven hypotheses with numerical decision rules make the theory falsifiable.

### What Is NOT Asserted
- NOT asserted: a physical sixth dimension exists.
- NOT asserted: the Cloud-Visibility Rule is established. It is a hypothesis.
- NOT asserted: any empirical result. No data exist.
- NOT asserted: spiritual, supernatural, medical, or therapeutic claims.
- NOT asserted: every person can reach the state.
- NOT asserted: originality is established. Originality is a claim to be verified.

## Approach
- State the claim clearly. Define it by measurement. State in advance what would falsify it. Register it. Test it. Report the outcome, whatever it is.
- Weight objective measures (R, B) above self-report (U). Score D automatically, blind to V. Audit every counterexample.
- Publish the full protocol before data, and the full verdict matrix before results.
