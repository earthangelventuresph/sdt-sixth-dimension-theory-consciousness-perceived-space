## E5 — Independent Replication (Dome)
- **Claim:** E2 result replicates in an independent lab / team with the same frozen protocol.
- **Formal Prediction:** Same H3 thresholds: k = 0 strong form; pU ≤ 0.05 operational form.
- **Falsification:** Same as E2. Non-replication = rule not general, even if E2 supported it.
- **Design / Sample:** Pre-registered replication, N ≥ 60, same dome specification, same MVIS-1 / PSQ-6 / probes.
- **Blinding / Analysis:** Same automatic D-blind-to-V pipeline. Independent audit.
- **Confounds / Safety / Data:** Same as E2. No data exist.

## E6 — Long-Term Stability and Test–Retest
- **Claim:** G, Q, D are stable enough within a participant to be a trait-like state measure, not a one-off artefact.
- **Formal Prediction:** Test–retest reliability of G pre-registered (e.g. ICC threshold stated in frozen E6 protocol before data).
- **Falsification:** If pre-registered reliability threshold is not met, G is not accepted as a stable state measure as defined.
- **Design / Sample:** Repeated sessions, same participant, same conditions, pre-registered interval.
- **Blinding / Analysis:** Frozen analysis; no threshold changes after data.
- **Confounds / Safety / Data:** Practice, fatigue, expectation. Same safety as E1. No data exist.

## E7 — Individual Differences: VVIQ, Aphantasia, Attention
- **Claim:** VVIQ / imagery vividness moderates G, but does not explain away the Cloud-Visibility Rule.
- **Formal Prediction:** VVIQ entered as covariate; rule (H3) holds within vividness strata at pre-registered thresholds.
- **Falsification:** If rule fails in high-vividness stratum, or VVIQ fully accounts for G differences, the moderation claim is rejected as stated.
- **Design / Sample:** Stratified analysis of E1–E4 data + dedicated sample if needed, pre-registered.
- **Blinding / Analysis:** Frozen covariate model. No post-hoc strata.
- **Confounds / Safety / Data:** Aphantasia is not an exclusion. Same safety. No data exist.

## E8 — Other External Structures (Generalised Anchoring)
- **Claim:** Eq. 24 generalises: other visible structures (buildings, trees, patterned surfaces) anchor like cloud, with their own Λi, ci, c0,i.
- **Formal Prediction:** G ceiling falls with Λi per Eq. 24; equivalence tests at pre-registered δ.
- **Falsification:** If matched non-cloud structures do not anchor within pre-registered equivalence bounds, generality is rejected.
- **Design / Sample:** Dome, matched stimuli, Latin square, pre-registered N.
- **Blinding / Analysis:** Same D-blind-to-V pipeline, frozen equivalence tests.
- **Confounds / Safety / Data:** Luminance, contrast, spectrum matched. Same safety. No data exist.

## E9 — Night / Indoor / Eyes-Closed Boundary Conditions
- **Claim:** The rule is silent where V = 0 by definition (night, indoors, eyes closed). Those conditions neither support nor challenge the rule.
- **Formal Prediction:** No H3 test is run on night / indoor / eyes-closed trials. They are reported descriptively only.
- **Falsification:** This is a scope rule, not an empirical claim. It is violated if any future report counts V = 0 night/indoor trials as evidence for D = 1.
- **Design / Sample:** Descriptive boundary-condition report only. No H3 decision rule applied.
- **Blinding / Analysis:** Descriptive statistics only. No inferential claim from boundary conditions.
- **Confounds / Safety / Data:** Darkness, sleepiness, eye closure confounds are why no inference is drawn. Same safety. No data exist.
