## How to Report
- **Do NOT open a public issue for a security / privacy vulnerability.**
- Email: earthangelventuresph@gmail.com — Subject: "Security Report — EAV-SDT-001"
- Include: what you found, where, steps to reproduce, impact, and your contact.
- Do not include identifiable participant data in a report. No such data should exist in this repository.

## What Counts
- Exposure of private / identifiable data.
- Malicious link / file in a PR / issue impersonating this repository.
- Impersonation of official accounts.
- Vulnerability in analysis code / scripts that could leak data or corrupt results.

## What Does NOT Count
- Disagreement with the theory. Use correction.md.
- A hypothesis being wrong. That is falsification, not a security issue.
